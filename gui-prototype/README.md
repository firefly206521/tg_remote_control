# TG AI 本地 GUI

GUI 随 `main.py` 一起启动。请使用 `open-gui.bat` 或从启动日志复制带 `token` 的完整地址打开，统一入口默认端口为 `8765`。双 Bot 模式下它会聚合 Codex 和 Claude 任务；`8766` 是 Claude 的本机后端端口，不需要单独打开。

网页只绑定本机 `127.0.0.1`，不会监听局域网地址。网页与 Telegram 共用任务和执行队列，但各自保存当前选中的任务，网页切换不会改变 Telegram 的当前任务。

## 可用操作

- 搜索并切换任务，查看 AI、工作目录、实时活动和队列状态。
- 输入草稿，切换其他任务或刷新页面后再回来，草稿保留在当前浏览器。
- 新建真实任务并选择 AI 和工作目录；目录必须已经存在。
- 发送消息到明确选中的任务；任务运行中继续发送会进入该任务队列。
- 停止明确选中的任务并清空它的等待队列，其他任务不受影响。
- Enter 发送，Shift + Enter 换行；中文输入法确认候选词不会发送。非输入状态按 N 新建。
- “任务信息”可折叠；窄窗口中任务列表变为横向排列。

升级后的用户消息、AI 回复和结束状态保存在 `history.sqlite3`。旧平台对话历史未曾落盘，因此不会显示在网页中。

## 当前边界

Telegram 任务按钮和 AI 主动通知尚未实现；在 Telegram 中使用 `/sw` 和 `/sw 任务名` 进入网页创建的同一任务。

## 测试

从项目根目录运行 `python -m unittest test_runner.py test_webui.py -v`，再运行 `node --check gui-prototype/app.js`。浏览器视觉验收情况见 `VALIDATION.md`。
